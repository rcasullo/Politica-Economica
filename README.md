# Politica Economica — Corso di recupero

Materiale didattico per un corso di recupero di Politica Economica, basato sulle slide del corso ufficiale.

Il corso è articolato in quattro lezioni:

1. **Fondamenti microeconomici** — concorrenza perfetta, teoremi del benessere, fallimenti del mercato e politiche pubbliche microeconomiche
2. **Fallimenti macroeconomici e modelli teorici** — ciclo, disoccupazione, inflazione, IS-LM, AD-AS
3. **Teoria normativa e politica monetaria**
4. **Politica fiscale, dei redditi e bilancia dei pagamenti**

Per ciascuna lezione sono disponibili:
- note di lezione in HTML
- quiz di ripasso a scelta multipla

## Modalità presentazione

Tutte le pagine supportano una modalità presentazione (font ingranditi, layout più ampio) attivabile con il **tasto P** o il pulsante in alto a destra.

## Sito

Le pagine sono ospitate su GitHub Pages e possono essere proiettate direttamente in aula.
